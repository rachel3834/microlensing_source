There are a number of real and simulated datasets including microlensing events, 
which are useful both to explore and for software testing. 

## Real datasets
The [NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/docs/data.html) 
hosts a number of datasets relevant to microlensing.  The lightcurves for planetary 
events are available from the planets table, and the following survey data releases  
are also available. 

* [UKIRT microlensing survey](https://exoplanetarchive.ipac.caltech.edu/cgi-bin/TblSearch/nph-tblSearchInit?app=ExoTbls&config=ukirttimeseries)
* [MOA microlensing survey](https://exoplanetarchive.ipac.caltech.edu/cgi-bin/MOA/nph-firefly?MOA)
* [ROME/REA microlensing survey](https://exoplanetarchive.ipac.caltech.edu/cgi-bin/ROME/nph-firefly?data&filter=True)
* [DREAMS microlensing survey](https://astro.westlake.edu.cn/dreams/)

In addition many of the ground-based surveys provide reduced data products 
for events discovered in real-time.  See the [Ground-based Surveys]({{ '/observations/ground-based-surveys/' | relative_url }}) for 
more information. 

## Simulated datasets
* [The 2018 microlensing data challenge dataset](https://zenodo.org/records/18041245)
* [The PLAsTiCC data challenge from the LSST](https://zenodo.org/records/2539456)
* [DESC ELAsTiCC data challenge from the LSST](https://portal.nersc.gov/cfs/lsst/DESC_TD_PUBLIC/ELASTICC/)
